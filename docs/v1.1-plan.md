# NovaFlow AI v1.1 开发计划

> 版本目标：企业集成增强（SSO · 组织架构 · 成本分摊 · 外部告警）  
> 前置条件：v1.0.1 已交付（Studio 开发中台 + Open API / Embed）  
> 关联文档：[PRD §8.3.1](./PRD.md) · [README v1.0 产品形态](../README.md)

---

## 1. 版本范围

| 模块 | 优先级 | 说明 |
|------|:------:|------|
| SSO（OAuth2/OIDC） | P0 | 企业单点登录，替代纯邮箱密码（保留作为 fallback） |
| 部门组织架构 | P0 | 树形部门、成员归属、按部门授权（PRD 延后项回收） |
| 成本分摊报表 | P1 | 按应用 / 工作空间 / 用户维度 Token 与费用汇总 |
| 外部告警通道 | P1 | 邮件 / Webhook，对接账单预警与可观测告警 |

**明确不在 v1.1：** Portal 用户前台、独立 Platform Admin 超管端（规划 v1.2）。

---

## 2. 里程碑建议

| 阶段 | 周期（参考） | 交付物 |
|------|-------------|--------|
| M1 基线冻结 | 1 周 | v1.0.1 提交/tag、集成测试 + E2E 绿灯、开 `release/1.1` 分支 |
| M2 SSO | 2–3 周 | OAuth2/OIDC 登录、租户级 IdP 配置、登录页与回调 |
| M3 组织架构 | 2 周 | 部门 CRUD、成员挂部门、权限与菜单按部门过滤（可选） |
| M4 成本分摊 | 1–2 周 | 报表 API + 账单页分摊视图 + 导出 |
| M5 外部告警 | 1–2 周 | 告警规则 + 邮件/Webhook 发送 + 失败重试 |
| M6 发布 | 1 周 | 文档、changelog、私有化 compose 验证、v1.1.0 tag |

## 3. 任务清单（按模块）

### 3.1 SSO（OAuth2/OIDC）

**后端**

- [ ] 新增 `novaflow-security` OAuth2 Client 配置（Authorization Code + PKCE）
- [ ] 租户级 IdP 配置表与 CRUD（issuer、clientId、clientSecret 加密存储）
- [ ] `AuthController` 增加 `/auth/oauth2/authorize`、`/auth/oauth2/callback`
- [ ] 首次 SSO 登录：按 email/domain 匹配或绑定已有用户；可选自动建用户
- [ ] 登录页提示与 PRD 对齐（v1.1 启用 SSO 后更新文案）
- [ ] 集成测试：Mock IdP 或 Testcontainers Keycloak

**前端**

- [ ] 登录页「企业 SSO 登录」按钮（租户 slug 或域名识别）
- [ ] 设置页：企业管理员配置 SSO（Client ID / Secret / Issuer）
- [ ] 回调页处理 token 写入 Pinia + 跳转 dashboard

**配置 / 部署**

- [ ] `application-prod.yml` 增加 OAuth2 redirect URI 说明
- [ ] README / 私有化部署文档补充 SSO 环境变量

### 3.2 部门组织架构

**数据层**

- [ ] Flyway：`department` 表（tenant_id、parent_id、name、sort、path）
- [ ] `organization_member` 或 user 扩展 `department_id`
- [ ] 索引与租户隔离校验

**后端**

- [ ] `DepartmentController`：树形列表、CRUD、移动节点
- [ ] `OrganizationService` 扩展：成员分配部门、按部门查询成员
- [ ] 权限：仅 `tenant:manage` / `member:manage` 可改架构
- [ ] 可选：数据范围过滤（部门管理员只看本部门成员）

**前端**

- [ ] `org/index.vue` 增加部门树（Ant Design Tree）+ 成员归属
- [ ] 成员邀请/编辑表单增加部门选择

**测试**

- [ ] 集成测试：部门 CRUD、成员归属、跨租户隔离

### 3.3 成本分摊报表

**后端**

- [ ] 基于现有 `token_usage` 聚合：按 application_id、workspace_id、user_id 维度
- [ ] `BillingController` 新接口：分摊汇总、趋势、Top N

**前端**

- [ ] `billing/index.vue` 增加「成本分摊」Tab：应用 / 工作空间 / 用户切换
- [ ] 图表（ECharts）+ 表格导出（复用现有导出能力）

**测试**

- [ ] 集成测试：写入 usage 后分摊 API 数值正确

---

### 3.4 外部告警通道

**后端**

- [ ] 告警通道配置表：type（email/webhook）、endpoint、secret、enabled
- [ ] 扩展 `BillingAlertService` / 可观测告警：触发时异步发送
- [ ] Webhook 签名（HMAC）+ 邮件 SMTP 配置（环境变量或租户配置）
- [ ] 发送失败重试与审计日志

**前端**

- [ ] 系统设置或账单页：配置告警通道、测试发送
- [ ] 可观测性页：告警历史列表（可选）

**测试**

- [ ] 单元/集成：Mock SMTP / Webhook server 验证 payload
