# NovaFlow AI v1.1 开发计划

> 版本目标：**应用门户** + 组织增强 + 运营能力（成本分摊 · 外部告警）  
> 前置条件：v1.0.1 已交付（Studio + Open API / Embed）  
> 产品形态：**一套登录**，按角色进入总控 / Studio / 应用门户  
> 关联文档：[PRD §8.3.1](./PRD.md) · [README](../README.md)

---

## 1. 版本范围（2026-09 调整）

| 模块 | 优先级 | 说明 |
|------|:------:|------|
| **应用门户** | **P0** | 应用中心、对话入口、会话历史 |
| 部门组织架构 | P0 | 树形部门、成员归属 |
| 成本分摊报表 | P1 | 按应用 / 工作空间 / 用户维度汇总 |
| 外部告警通道 | P1 | 邮件 / Webhook |
| SSO（OAuth2/OIDC） | **延后** | 需独立 IdP 服务器联调 |

**不纳入规划：** 三套独立前端 / 分端口分壳部署。总控与门户均为同站路由。
