你的项目本身是企业级 AI Agent SaaS，权限体系会直接影响后面的 Agent、知识库、Workflow、模型、API 和数据隔离。多租户系统尤其要同时解决“用户属于哪个租户”和“用户在该租户能做什么”两个问题；不能只靠前端隐藏按钮，后端 API 和数据层也必须强制校验租户边界。

十四、后端权限链路

NovaFlow 推荐：

HTTP Request
      ↓
JWT / Session
      ↓
Authentication
      ↓
Tenant Context
      ↓
RBAC
      ↓
Resource Permission
      ↓
Business Permission
      ↓
Service
      ↓
Database

例如：

POST /api/agents/10001/publish

后端检查：

① 用户是否登录？

② 用户属于哪个 Tenant？

③ Agent 10001 属于哪个 Tenant？

④ 两个 Tenant 是否一致？

⑤ 用户有没有 agent:publish？

⑥ 用户是否拥有 Agent 10001 的发布权限？

⑦ Agent 当前状态是否允许发布？

⑧ 执行发布

这才是企业级方案。
