# NovaFlow v1.3 开发计划

> 版本目标：**运营闭环** + **终端体验** + **开发者集成**  
> 前置条件：v1.2.0 已交付  
> SSO 仍延后（需 IdP 环境）

## 里程碑

| 里程碑 | Phase | 内容 | 状态 |
|--------|-------|------|------|
| M1 运营告警闭环 | 35 | 平台风控/API 监控/存储配额 → 邮件/Webhook 外发 | ✅ |
| M1 | 36 | 存储配额硬拦截（上传前校验） | ✅ |
| M2 平台角色与部署 | 37 | 平台子角色扩展（support/billing） | ✅ |
| M2 | 38 | admin 独立 Docker Compose 栈 | ⏳ |
| M3 终端用户 | 39 | 应用门户增强（收藏/分类/导出/移动端） | ✅ |
| M3 | 40 | 门户品牌化（Logo/主题色） | ✅ |
| M4 开发者 | 41 | Embed 增强（主题/域名白名单/postMessage） | ✅ |
| M4 | 42 | Open API 开发者中心（发布页 Quick Start） | ✅ |

## Phase 35 已交付

- `platform_notify_channel` 表 + `GET/PUT /v1/platform/notify-channels`
- `POST /v1/platform/notify-channels/test` 测试通知
- 系统配置：`notify.security_channels` / `notify.api_monitor_channels` / `notify.storage_quota_channels`
- 风控/API/存储告警触发外发（存储在运营大盘加载时扫描）
- 平台设置页「外部告警通道」与「告警外发策略」UI
- 冒烟：`test/platform-alert-dispatch-smoke.ps1`

## Phase 36 已交付

- 知识库上传前 `TenantStorageQuotaService` 硬校验（`BizErrorCodes.STORAGE_QUOTA_EXCEEDED = 40036`）
- `GET /api/v1/knowledge-bases/storage-usage` 租户存储用量
- 账单配额 API 返回 `usedStorageBytes` / `storageUsedPercent`
- 知识库详情页配额进度条与满额禁用上传
- `platform-storage-quota-smoke.ps1` 覆盖 P36 拦截场景

## Phase 37 已交付

- 平台子角色：`platform_support`（租户查看/运营）、`platform_billing`（计费查看 + 租户只读）
- 权限码：`platform:tenant:view`、`platform:tenant:manage`、`platform:billing:view`
- `PlatformAdminService` / `PlatformAdminController` 按子权限分层校验
- 演示账号：`support@novaflow.ai` / `billing@novaflow.ai`
- 前端菜单与路由按子角色过滤；默认首页：客服→租户管理、计费→计费大盘
- 冒烟：`test/platform-sub-roles-smoke.ps1`

## Phase 39 已交付

- 门户应用收藏：`POST /api/v1/portal/favorites/toggle`，列表支持 `favoritesOnly`
- 门户分类：`application.portal_category`、 `GET /api/v1/portal/categories`、应用编辑页分类选择
- 对话导出：`GET /api/v1/portal/apps/{id}/conversations/export`（markdown/json）
- 门户侧栏分类筛选、收藏按钮、历史对话导出与移动端布局优化
- 冒烟：`test/portal-enhancements-smoke.ps1`

## Phase 40 已交付

- 租户门户品牌化：`tenant.portal_theme_color`、组织管理页 Logo/主题色配置
- `GET /api/v1/portal/branding` 门户加载品牌信息并应用主题色 CSS 变量
- 冒烟：含于 `test/portal-enhancements-smoke.ps1`

## Phase 41 已交付

- `agent.embed_config` JSON：主题色、域名白名单、postMessage 目标 Origin
- `GET/PUT /api/v1/agents/{id}/embed-config`；发布信息返回 `embedConfig`
- Open API Embed Token 校验 Referer/Origin 域名白名单（40304）
- welcome 响应返回 `embedThemeColor` / `postMessageTargetOrigin`
- 嵌入页应用主题色 CSS 变量；向宿主页 postMessage（`ready` / `message` / `error`）
- 冒烟：`test/embed-domain-smoke.ps1`

## Phase 42 已交付

- Agent 发布弹窗升级为「开发者中心」：Quick Start / Open API / Embed 三 Tab
- Quick Start 步骤说明、凭证权限对比、Swagger 链接
- Open API Tab：端点列表、同步/流式 cURL、`X-Caller-Id` 说明
- Embed Tab：iframe 宽高生成器、配置表单与嵌入代码复制
