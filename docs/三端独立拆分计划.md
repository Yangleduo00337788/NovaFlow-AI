# 三端独立拆分计划（已取消）

> **状态：已取消（2026-09）**  
> 产品改为 **单一 Web 应用 + 一套登录 + RBAC 功能分区**，不再拆 Studio / Portal / Platform 三套前端。

原方案（Vite 多 mode、端口 3000/3001/3002、独立 Nginx）不再实施。当前约定：

| 项 | 现状 |
|----|------|
| 前端 | `novaflow-web` 单应用，`npm run dev` → `http://localhost:3000` |
| 登录 | `/login` 一套入口，后端不再校验 `terminal` |
| 功能区 | 超管 → `/platform`；普通用户 → `/portal`；其余 → `/dashboard` |
| 门户预览 | 管理员/开发者可进入 `/portal`；门户内「返回工作台」 |
| 门户路径 | `/portal`、`/portal/apps/:id` |
| 部署 | 一个 `web` 容器（见 `deploy/docker-compose.prod.yml`） |

Embed 仍为独立公开页：`/embed/agents/{id}`。
