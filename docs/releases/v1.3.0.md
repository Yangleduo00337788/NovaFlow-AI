# NovaFlow AI v1.3.0

**发布日期：** 2026-09-09

运营告警闭环、门户终端体验与开发者集成能力交付。平台子角色、存储配额硬拦截、Embed 域名白名单与发布页开发者中心纳入本版本。admin 独立 Docker Compose 不做（总控继续同站 `/platform`）。SSO 仍延后。

## 运营告警与配额

- **Phase 35** 平台告警外发：风控 / API 监控 / 存储配额可通过邮件与 Webhook 外发；设置页支持通道配置与测试
- **Phase 36** 存储配额硬拦截：知识库上传前校验，满额禁止上传；账单与知识库页展示用量

## 平台角色

- **Phase 37** 平台子角色：`platform_support`、`platform_billing`；演示账号 `support@novaflow.ai` / `billing@novaflow.ai`
- 控制台菜单与默认首页按子权限裁剪
- 租户侧收敛为三种系统角色：平台管理员、企业管理员、普通用户（Flyway V52）

## 应用门户

- **Phase 39** 收藏、分类筛选、对话导出（Markdown / JSON）、移动端布局
- **Phase 40** 租户门户品牌化：Logo 与主题色

## 开发者集成

- **Phase 41** Embed 增强：主题色、域名白名单、向宿主页 postMessage
- **Phase 42** Agent 发布页「开发者中心」：Quick Start / Open API / Embed 三 Tab

## 工程与质量

- 全量发布门禁 72 项通过（`run-pre-release-gates.ps1`）；升至 1.3.0 后需先 `mvn -DskipTests install` 再跑依赖本地模块的集成测试
- CI 集成 / E2E / Embed CORS 与三角色 RBAC 对齐

## 不做与延后

- **Phase 38** admin 独立 Docker Compose：**不做**。子域构建仍可用 `npm run build:platform`（见 [平台后台独立部署](../deploy-admin.md)）
- **SSO**（OAuth2 / OIDC）延后，需独立 IdP 环境

## 升级说明

- 自 v1.2.0 升级需执行 Flyway 迁移至 **V52**（含通知通道、门户增强、Embed 配置、三角色收敛）
- 请确认 `NOVAFLOW_CRYPTO_KEY` 与既有环境一致后重建 Server + Web
