# NovaFlow AI v1.2.0

**发布日期：** 2026-09-06

平台总控运营能力全面增强，补齐风控与存储配额闭环。面向 SaaS 运营方的租户治理、计费导出、API 监控与模型目录等能力在本版本交付。

## 平台总控

- 平台运营后台独立化：`/platform/login` + 多页面路由，支持 admin 子域独立部署（`npm run build:platform`）
- 租户治理：代开户、租户详情/健康度、配额进度、计费 CSV 导出、用户封禁与强制下线
- 运营大盘：租户增长/Token 趋势图表、API 调用监控与告警处置、模型供应商治理与平台模型目录
- **Phase 31** 代开户增强：自动生成 Owner 密码、邀请邮件、套餐模板、Owner 密码重置
- **Phase 34** 维护模式/公告：配置中心开关，Studio / Portal 维护页与公告横幅
- 平台子角色：`platform_auditor` 只读审计；注册开关运行时生效

## 风控与配额

- **Phase 32** 平台风控：同 IP 批量注册限制、异常登录与新设备登录告警、安全中心风控 Tab
- **Phase 33** 存储配额：租户已用存储统计、`maxStorageMb` 对比、列表/详情/健康度进度展示

## 工程与质量

- 全量发布门禁 53 项通过（`run-pre-release-gates.ps1`）
- 自定义角色与平台/租户账号域隔离（Phase 11）
- Model / Tool / MCP / Prompt 资源 ACL（Phase 10）
- RBAC 矩阵与门户/全局搜索资源 ACL 对齐

## 升级说明

- 自 v1.1.x 升级需执行 Flyway 迁移至 V46
- 平台风控相关配置见 `/platform/settings` 与 `/platform/security`
- SSO（OAuth2/OIDC）延后至 v1.3+
