NovaFlow AI v1.3.0
发布日期： 2026-09-09
类型： 正式发布
基于： v1.2.0

概述
运营告警闭环、门户终端体验与开发者集成：告警外发、存储配额硬拦截、平台子角色、门户收藏/分类/导出与品牌化、Embed 域名白名单与开发者中心。admin 独立 Docker Compose 不做。SSO（OAuth2/OIDC）仍延后。

本版本新增

运营告警与配额（Phase 35 / 36）
- 平台告警外发：风控 / API 监控 / 存储配额可通过邮件与 Webhook 外发
- 存储配额硬拦截：知识库上传前校验，满额禁止上传

平台角色（Phase 37）
- 平台子角色：platform_support、platform_billing
- 租户侧三种系统角色：平台管理员、企业管理员、普通用户

应用门户（Phase 39 / 40）
- 收藏、分类筛选、对话导出、移动端布局
- 租户门户 Logo 与主题色

开发者集成（Phase 41 / 42）
- Embed：主题色、域名白名单、postMessage
- 发布页开发者中心：Quick Start / Open API / Embed

权限与工程
- 全量发布门禁 72 项通过
- 升至 1.3.0 后需先 mvn -DskipTests install 再跑依赖本地模块的集成测试

不做与延后
- Phase 38 admin 独立 Docker Compose：不做（总控继续同站 /platform）
- SSO 延后

升级说明
从 v1.2.0 升级建议：

- 拉取 v1.3.0 或 master 分支
- 执行数据库迁移（Flyway 自动执行，至 V52）
- 确保 NOVAFLOW_CRYPTO_KEY 与部署环境一致
- 重新构建并部署 Server + Web 镜像

```
git checkout v1.3.0
mvn clean package -DskipTests
cd novaflow-web && npm install && npm run build
```
